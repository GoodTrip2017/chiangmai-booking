合作與活動追蹤連結 / Tracking links

想知道客人從哪個入口進來，就替每個入口建立一個代碼（例如 ig、threads、line、hotel-xxx），類型選「活動」或「合作」，把各自的網址貼到該平台的簡介或給合作店家。客人從那個網址進來預約，就會記在那個代碼下；成效在「數據分析 → 追蹤來源與合作代碼」。代碼建立後不能改，名稱可以隨時改。
Create one code per entry point (for example ig, threads, line, hotel-xxx), paste each link in that channel's bio or hand it to the partner. Bookings made through a link are attributed to its code; see Analytics → Tracked links & partners. Codes are fixed; names can be edited any time.

營業與容量 / Availability & Capacity

同一時間所有重疊預約合計不得超過設定容量，硬上限為 12 人。調整若影響既有預約，會先列出預約編號供確認；不會自動取消或改期。
Overlapping bookings share the same capacity, capped at 12 guests. Existing affected bookings are shown before applying changes.
